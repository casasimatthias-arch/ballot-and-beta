# Ballot & Beta

*Every stock has a market beta. I measure its ballot beta.*

Ballot & Beta is a public research project that measures how political and regulatory events, such as elections, referendums and new regulation, move stock prices. Each study uses the classic event-study method (MacKinlay, 1997): a market model is estimated over a quiet period before the event, the abnormal returns around the event are measured against it, and those are summed into cumulative abnormal returns (CAR/CAAR) and tested for statistical significance. The project is run by Matthias, a first-year student learning finance and Python, and every result is checked against a hand-calculated Excel benchmark before it is published.
